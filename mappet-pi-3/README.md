# MAPPET PI III

**Previsto para o 1º semestre de 2027**

## O que está planejado

Ao fim do PI II, o MAPPET tem duas partes separadas: a interface web, que ainda guarda os dados no navegador, e o módulo desktop em Java, que já grava tudo no Oracle. O próximo passo é unir as duas:

* levar as regras do módulo desktop para um back end em Java rodando no servidor;
* fazer a interface web consumir esse back end, usando o mesmo banco Oracle e o mesmo modelo de dados;
* passar a exigir login na web para ver o contato do acolhedor, registrando o interesse antes, como já acontece no desktop;
* permitir que o tutor encerre o anúncio quando o pet for reencontrado, com limite de anúncios ativos por usuário.

Com isso, o módulo desktop deixa de ser necessário.
